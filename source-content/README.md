# source-content

Matériel brut du site WordPress actuel, utilisé uniquement pour migrer le contenu vers Astro. **Rien ici n'est publié** : ce dossier n'est pas dans `src/` ni `public/`.

- `html/` — le HTML des pages actuelles (une page = un fichier, ex. `accueil.html`, `la-distillerie.html`, `contact.html`). Idéalement : « Enregistrer sous → Page web, HTML uniquement », ou le code source (Ctrl+U) de chaque page. Indiquer l'URL d'origine en commentaire en première ligne : `<!-- https://ampov-distillery.com/... -->`.
- `images/` — logos, photos de produits et visuels fournis.

Une fois les contenus repris dans `src/`, ce dossier peut être supprimé.
